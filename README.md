# Site VERT4®

Projeto institucional da VERT4®, pronto para edição no VS Code.

## Estrutura

- `dist/index.html`: conteúdo e estrutura da página
- `dist/styles.css`: identidade visual e responsividade
- `dist/assets`: logo e símbolo vetorial

## Visualização local

Abra `dist/index.html` no navegador ou use a extensão Live Server no VS Code.

## Fluxo de atualização

1. Edite os arquivos.
2. Salve as alterações.
3. Faça commit e push para a branch `main`.
4. Solicite a publicação da nova versão do Site.
